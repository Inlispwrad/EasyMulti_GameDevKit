# Setting up your own relay · 自分でリレーを立てる · 自己部署中继

A step-by-step tutorial for people who have **never deployed a server**. It starts at
"I have a fresh Linux box and an IP address" and ends at "my game is talking through it",
explaining what every command does and what to check when something goes wrong.

サーバーを立てたことがない方向けの、手順を追ったチュートリアルです。

给**从来没有部署过服务器**的人看的手把手教程。
